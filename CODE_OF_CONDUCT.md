# Code of Conduct

OmniSession has one simple rule: treat people well and keep the focus on the work.

## Expected behavior

- Be respectful, constructive, and specific.
- Assume good intent and ask questions before drawing conclusions.
- Critique ideas and code, not people.
- Protect privacy. Coding-agent transcripts often hold other people's code and data, so share only synthetic or scrubbed material.

## Not accepted

- Harassment, insults, or personal attacks.
- Discrimination of any kind.
- Disclosure of another person's private data, credentials, or transcripts.
- Sustained disruption of issues, pull requests, or reviews.

## Scope

This code applies in all project spaces, including issues, pull requests, reviews, and commit messages.

## Reporting and enforcement

Report conduct concerns privately through repository maintainers. Don't post reports publicly.

Maintainers may edit or remove content, lock conversations, or block participants who break this code.
